# もじ・ことばクエスト (moji-quest)

ひらがな・カタカナ・ことばを楽しく学べる幼児向け知育Webゲームです。

🌟 **公開URL**: [https://mr-p4754.github.io/moji-quest/](https://mr-p4754.github.io/moji-quest/)

---

## 🎮 ゲームの特徴

- **直感的な縦5段（あ〜お段）キーボード**:
  - 五十音図に基づいた配置で、幼児でも文字の並び順や母音の感覚を自然に学習。
  - 下段には濁音・半濁音・拗音（きゃ・きゅ・きょ等）を直結配置し、横スクロールなしで1画面ですべての文字を見渡せます。
- **フル音声読み上げ（Web Speech API）**:
  - 親しみやすい高めの声で「『か』どぉれだ？」と出題。
  - ボタンを押した瞬間に文字が画面に表示され、その文字の発音が流れます。
- **おしい！の励まし演出**:
  - 間違えても否定せず、「うーん、おしい！もう一度かんがえてみてね！」とやさしく応援。
  - 音声が流れ終わると問題エリアの表示が「？」に戻り、何度でも挑戦できます。
- **はなまる＆ファンファーレ**:
  - 正解時には💮はなまる演出と「ピンポーン」効果音で達成感を高めます。
- **選べる出題モード**:
  - 🌟 すべて
  - 🌸 50音のみ
  - 🍃 濁音・半濁音のみ
  - 🌿 拗音（しゃ・しゅ・しょ等）のみ
- **PWA（Progressive Web App）対応**:
  - スマートフォンやタブレットのホーム画面に追加してアプリ感覚で遊べます。

## 🛠 技術スタック

- **フロントエンド**: HTML5, Vanilla CSS, Vanilla JavaScript (ES Modules)
- **音声合成**: Web Speech API (`SpeechSynthesisUtterance`)
- **効果音**: Web Audio API (オシレーターによるリアルタイム合成)
- **オフライン対応**: Service Worker (Cache Storage)
- **ホスティング**: GitHub Pages
